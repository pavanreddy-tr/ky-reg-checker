How to populate the regulation database
The database needs to be populated once with all regulation text. Run the fetch script:

node scripts/fetch-regulations.js

This downloads all 40 CFR Parts 60, 61, 63 subparts and all 401 KAR chapters automatically from eCFR and Kentucky LRC. Takes about 10–15 minutes to complete.
